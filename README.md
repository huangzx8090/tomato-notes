# 番茄小记

原生 macOS 状态栏工具：番茄钟、待办、浮动便签、**DeepSeek 工作与成果回顾** 与 **Chrome 专注守护**。

需求基础为 [项目需求书](番茄小记_项目需求书.md)。后续用户要求优先于原文：支持合盖外接显示器工作；新增每轮文字与图片 AI 总结、每天定时 AI 回顾和仿真旋钮。

## 使用 AI 回顾

1. 在 **设置 → AI 工作与成果回顾** 保存 DeepSeek API Key，点击“测试连接”。接口与支持图片的 `deepseek-flash` 模型已经预设。
2. 直接开始专注即可；也可选一个待办或写下本轮目标。每轮会自动留下目标、实际投入和专注期间勾选完成的待办，进展卡和“今日 → 时间都变成了什么”都可打开详情。
3. 可开启 **专注结束后自动整理 AI 回顾**：默认关闭，开启后新结束且实际投入至少 1 分钟的轮次会在后台整理一次，不要求写复盘、不额外弹窗、不补跑历史。失败保留记录，不自动重试。
4. 想让成果更具体时，在进展详情展开 **补充一句或图片（可选）**，添加文字或成果图，点击“让 AI 总结工作与成果”。也可在 **今日 → AI 每日回顾** 手动汇总，或设置每天的生成时间。

AI 按“做了什么 / 取得的成果 / 待继续 / 待确认”整理结果。全天汇总会先解析尚未总结或已经修改的各轮文字与图片，再综合当天的专注记录、待办和补充内容。已有结果可重新生成或复制。

进展卡在本机生成，不需要 API Key；目标代表计划，App 时长代表投入，二者都不会自动记成“任务完成”。具体成果来自勾选完成的待办、用户描述或图片。暂停和休息期间勾选的任务不会自动归入上一轮；提前结束也保留实际投入。自动 AI 开关与定时日报独立，均需用户主动开启。

每条成果最多 6 张图片，每张原文件最多 25 MB，支持 PNG、JPEG、HEIC、WebP。导入时转换为最长边不超过 1600 像素的 JPEG；生成时发送用户选定的图片。只导入或编辑不会调用 AI。

定时生成需要应用保持运行。应用退出或系统睡眠期间不执行；当天已过时间，重新启动或解锁后补生成。完成一次定时尝试后当天不重复自动调用；失败保留材料和旧总结，支持手动重试。生成过程中退出，重启后可重新执行未完成的定时任务。

详见 [AI 功能与验证说明](docs/AI工作与成果回顾.md)。

## Chrome 专注守护

在 **专注 → 专注守护** 为这一轮填写学习目标、允许的 App，以及 Chrome 的页面 / 网站白名单。设置中可以开启每轮开始前选择白名单，并调整停留提醒、提醒后的等待秒数与每轮 AI 次数上限（默认 60 秒 / 60 秒 / 3 次）。

日常检查完全在本机运行，不截图、不调用 AI。非白名单停留超时后弹出轻提醒；只有用户在本轮开启“允许 AI 确认后关闭无关 Chrome 标签页”，等待后仍未返回，才截取当前普通 Chrome 窗口发送给 DeepSeek 做最后判断。明确无关且置信度至少 0.9 才关闭对应标签，相关、无法确定、超时或错误都不主动关闭。其他 App 只提醒。

“此页”保留网址查询条件，以区分同一视频网站内不同课程和娱乐视频；“网站”允许该域名及其子域名。生效的白名单仅存在本轮内存，暂停保留，结束后失效。**自动沿用上轮目标与白名单** 默认关闭；开启后将保存名单并在后续开始时应用到新一轮，无需每次重新选择。AI 关闭授权始终不沿用，新一轮默认仅提醒；需要关闭时在该轮单独开启。关闭沿用开关会清空保存的名单。支持 Chrome 自动化与屏幕录制的显式授权，截图不保存，不读取无痕窗口内容，不注入网页脚本。详见 [专注守护说明](docs/Chrome专注守护.md)。

## 构建与运行

支持 macOS 14+。本机验证环境：macOS 27.0.1、Apple Silicon、Swift 6.4 Command Line Tools。没有第三方依赖。

```bash
Scripts/build-app.sh
open 'build/番茄小记.app'
```

构建产物使用 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证。构建脚本整体替换应用包；已运行进程需要正常退出再打开才能使用新代码。

默认状态栏运行，设置可开启 Dock 图标。点击菜单栏或 Dock 打开面板，Esc 收起。收起面板不停止计时。

## 计时、待办与便签

- 默认 25/5/15 分钟，每 4 轮长休息；暂停、继续、提前结束和跳过休息；阶段结束后等待手动开始下一阶段。
- 计时参数使用仿真旋钮：转动或上下拖动调节，− / ＋ 和方向键精确微调，保存后供后续阶段使用。
- 背景保持暖米色纸感；**设置 → 外观 → 按钮玻璃效果** 立即切换并记住选择，同时作用于主面板和成果窗口的按钮。
- **设置 → 外观 → 配色** 支持跟随系统、浅色与深色；深色保留暖棕纸感和胡桃色旋钮，便签、成果回顾与白名单窗口一同适配。玻璃开关独立保存。
- macOS 26+ 的按钮与顶部切换栏采用原生 Liquid Glass，选中胶囊以弹性玻璃过渡流动到目标页面；旧系统回退到材质与滑动过渡。支持系统“减少透明度”和“减少动态效果”。
- 仅在专注运行时记录前台 App 名称和停留时长；无法归属和关闭记录的秒数分别保留。
- 每日汇总、历史日期、每日待办；多张纯文本浮动便签、自动保存、位置恢复、按行转待办。
- 合盖外接活动显示器时默认继续计时；可关闭该设置。锁屏、睡眠暂停，唤醒和重启后等待主动继续。

| 默认快捷键 | 功能 |
| --- | --- |
| Control + Option + P | 开始 / 暂停 / 继续 |
| Control + Option + T | 快速待办 |
| Control + Option + N | 呼出最近便签 |

快捷键采用 Carbon 独占注册；修改失败保留旧键并释放本次新增组合，支持换键、停用与内部重复检查。部分第三方应用使用的非独占监听不能被完整查询；发生冲突时可在设置中换键。

## 数据和密钥

正式数据目录：

```text
~/Library/Application Support/TomatoNotes/
  data.json
  Attachments/
  Backups/
```

计时使用单调时钟，约每 2 秒保存恢复检查点，关键动作立即原子保存。相同数据目录只允许一个进程写入，重复启动会唤出原实例。读取失败保留原文件并停止写入。

数据格式已升级为 v2，读取 v1 前先备份原始文件；待办、便签与历史继续保留。设置中的“备份数据”同时复制已关联的图片，图片保存在备份 JSON 同名的 `.assets/Attachments/` 文件夹。恢复时需同时恢复 JSON 与图片。

开发期间的两份用户资料已备份并合并到正式目录，原 `build/verification-data/` 和 `build/qa-data/` 保留。正式库保留了用户待办、便签和真实专注记录；合成验收待办没有迁入。

API Key 存在本机钥匙串，不写入 JSON、Git 或日志。也支持当前进程的 `deepseek` / `DEEPSEEK_API_KEY` 环境变量。终端临时变量不会自动传给 Dock 启动的应用，可在该终端执行一次：

```bash
swift run TomatoDataTool import-deepseek-key
```

基础计时与成果回顾不自动读取屏幕。可选的专注守护仅在本轮允许 AI 关闭且需要最后核对时申请并使用屏幕录制权限；只截取当前 Chrome 窗口，截图在内存中使用。AI 成果生成会把对应范围的记录、用户补充和所选图片发送到 DeepSeek；其余功能可离线使用。

## 验证与开发

```bash
Scripts/test.sh
Scripts/check-integration.sh
Scripts/build-app.sh release --qa
open -n 'build/番茄小记验证.app' --args \
  --data-dir "$PWD/build/my-qa-data" --show-panel --ui-test
```

当前 47 项规则与接口测试通过，涵盖计时、日期、数据升级、定时去重、图片导入及备份、DeepSeek 文字/图片请求，以及守护的停留 / 暂停规则、网址边界、保守关闭条件、输入隐私、窗口唯一匹配、用量解析、沿用授权隔离与外观兼容。新增进展测试覆盖目标逐轮隔离、暂停待办排除、跨日统计、自动 AI 开关 / 时长门槛 / 持久化去重、过期总结排除和旧数据兼容。集成检查使用真实独立进程验证数据锁和 Carbon 占用，无模拟系统按键。

本轮 Chrome 系统授权、自动关闭与新增界面交互仍待人工验收；规则测试与构建不替代实机证明。已完成的体验调整、后续建议与验收顺序见 [体验优化与后续建议](docs/体验优化与后续建议.md)。

验证包有独立 Bundle ID；不指定数据目录时默认使用 `TomatoNotes-QA`，不打开正式资料。`--ui-test` 显示 Dock 图标，`--ui-stay-open` 仅供界面检查时保持面板可见。

核心模块关系：

```text
面板 / 快捷键 / 便签 / 成果窗口
               ↓
            AppState
       ↙          ↘
 TimerEngine     ReviewContextBuilder
       ↓          ↓
 原始分段与统计   DeepSeekClient ← 选定图片 / 用户描述
       ↘          ↙
      LocalRepository 原子保存
```

`TomatoCore` 负责规则、数据和总结上下文；`TomatoSystem` 负责快捷键、钥匙串、图片处理和 DeepSeek 请求；`TomatoNotes` 负责界面与系统事件。
