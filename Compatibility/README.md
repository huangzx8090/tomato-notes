# 跨端资料兼容契约

`data-contract-v4.json` 是 macOS 与 Windows 共用的最小回归样例，不含真实用户资料或密钥。

- 两端都读取同一份样例，再序列化并检查核心字段、Apple 基准日期、Unicode、图片文件名与未知扩展字段。
- 不修改样例来“修复”一端测试。需要新增或改变格式时，两端共同评审，同时更新解析、迁移策略和文档。
- `schemaVersion` 的升级必须向前迁移并先备份；旧端不能覆盖更高版本资料。
- 未支持的字段在读取、编辑其他记录、保存后仍须保留。不要把“本端未使用”当成“可删除”。
- 默认数据目录只供本机当前用户使用。资料迁移通过备份完成，不允许两台设备同时写同一网络目录。

当前契约对应 v4。macOS 的自动活动、Chrome 守护等字段，Windows 可以展示受限或不展示，但保存时必须保留。
这不是自动同步协议，也不意味着 Keychain / DPAPI 密钥可跨端迁移。
