番茄小记 · 安装与首次使用

系统：macOS 14 或更新版本。Universal 安装包同时包含 Apple Silicon 与 Intel 架构。

1. 打开 DMG，将“番茄小记.app”拖入 Applications；或解压 ZIP 后移动到“应用程序”。
2. 如已有旧版，请先正常退出，再替换应用并重新打开。普通打开应用副本会复用同一本机资料库和已有计时实例。
3. 默认在屏幕顶部菜单栏显示计时图标；设置中可开启 Dock 图标。

首次打开
当前版本为 ad-hoc 签名，未使用 Apple Developer ID 签名，也未经过 Apple 公证。
若系统阻止打开，请先确认文件来自本项目的 GitHub Release；可用附件 SHA256SUMS.txt 校验（下载附件中的安装说明名为 INSTALL.txt）。
尝试打开后，在“系统设置 → 隐私与安全性”中按系统提示选择“仍要打开”。
详细说明：https://support.apple.com/zh-cn/102445

按需开启权限
- 通知：开始或测试提醒时申请。系统设置 → 通知 → 番茄小记。拒绝不影响计时和记录。
- 自动化 → Google Chrome：Chrome 白名单、AI 白名单推荐与可选自动记录需要。
  在“专注 → 专注守护”点“连接 Chrome”，或在“设置 → AI 助手 → AI 自动记录”点“允许读取 Chrome”。
- 屏幕录制（部分系统称“屏幕与系统音频录制”）：仅在本轮允许 AI 关闭无关标签时需要。
  在本轮守护中点“允许关闭前读取 Chrome 窗口”；按提示授权，必要时正常退出重开。
- 钥匙串：保存或读取 AI 服务商 Key 时可能询问。请核对请求来自你安装的番茄小记。
基础计时、待办、便签和前台 App 时长记录不要求辅助功能、输入监控或完全磁盘访问。

AI 与费用
基础功能离线可用；AI 功能需自行在“设置 → AI 助手”选择服务商并填写 API Key。
保存后获取模型列表并从下拉框选择；自定义服务商需填写 OpenAI 兼容接口地址。
成果图片与 Chrome 核对需要所选模型支持图文输入。
“测试连接”只查询模型接口，不生成总结；成功不代表图片/总结已完成真实验收。
AI 回顾会发送对应记录、描述和选定图片；自动总结、定时日报需主动开启。
日报可能先补齐多轮总结，因此一次日报操作可能产生多次 API 请求。
AI 白名单推荐由用户主动点击并逐项确认，发送目标、App 名称、普通网页标题与网站，不发送完整页面地址。
AI 自动记录默认关闭，开启后按所选来源保存 Chrome 标题/网站、便签变更与完成待办，并交给当前服务商识别主题和生成回顾。
自动记录不需要屏幕录制；暂停、休息和锁屏时停止采集。标题和文字本身仍可能含私人信息，请按需选择来源。
费用及服务端数据处理以所选服务商政策为准；请勿上传含密钥或敏感资料的图片。

Chrome 守护
默认本机提醒不消耗 AI。仅本轮允许 AI 关闭且提醒后仍停留，才发送当前普通 Chrome 窗口截图。
截图在内存使用，不写磁盘；可能包含窗口工具栏及其他可见信息。不采集系统音频。
白名单默认只对本轮生效；“自动沿用上轮目标与白名单”默认关闭。
即使沿用名单，AI 关闭授权也不沿用。其他 App 不自动退出，无痕窗口不读取或关闭。
页面改变、权限不足、AI 不确定或调用失败时不主动关闭。误关可尝试 Command + Shift + T 恢复。
请先用无重要表单的普通测试标签体验；恢复标签不保证恢复未提交内容。

数据与升级
正式资料：~/Library/Application Support/TomatoNotes/
日常启动共用上述目录；显式 --ui-test / --data-dir 才隔离，面板会显示资料模式和实际位置。
Key 按服务商保存在本机钥匙串，不在 data.json 中；AI_API_KEY 和服务商环境变量优先于钥匙串，兼容旧 DeepSeek Key。
升级前建议在“设置 → 数据与隐私”备份数据；备份 JSON 和同名 .assets 图片目录须一同保留。
v1.6.1（build 13）的资料格式为 v4，保留活动记录和待办安排历史，读取旧资料前自动备份。
v1.4.0 等旧版无法读取 v4；回退旧版应用需先恢复旧版兼容的整份 JSON 与关联图片备份。
计时应用退出、锁屏、睡眠时停止运行；重新进入后需主动继续。
定时日报需要应用运行，错过时间后会在当天重新运行且解锁时补尝试。
删除待办可从底部逐条撤销，关闭提示或退出后撤销记录失效；删除便签确认后不能在应用内撤销。

历史与待办
今日页的专注热力图只统计真实番茄专注；悬停显示当天时长，点击切换日期，“查看全部”可翻阅更早历史。
今日页搜索图标或应用主界面的 Command + F 打开历史搜索，只查本地已有文字，并打开原记录。
待办顶部展开“之前还有 N 项未完成”，可单项或批量“安排到今天”；保留来源日期，不复制任务，不自动结转。
未完成时可撤销本次安排；完成事项按实际完成日期统计，历史安排仍保留。
