# 番茄小记项目协作

先区分只读、修改与发布准备，遵守当前用户指令和适用的 `AGENTS.md`。已加载的约束无需重复整篇读取；本入口不额外授予提交、跨端实现或发布权限。

## 按任务选择资料

| 当前任务 | 需要时读取 |
| --- | --- |
| 理解代码、只读评审 | 先定位相关代码；需要架构背景时，从[项目详解目录](../../../docs/项目结构与实现详解.md#目录)选择对应模块 |
| 开始或继续改动 | [开始工作](../../../CONTRIBUTING.md#开始工作)：工作区、已有任务分支、最新基线与 hooks；需要新分支时查[命名与职责](../../../CONTRIBUTING.md#分支职责) |
| macOS 实现与验证 | [macOS 维护入口](../../../apps/macos/AGENTS.md#构建与测试)，按影响选择规则测试、编译和实机验收 |
| Windows 实现与验证 | [Windows 维护入口](../../../apps/windows/AGENTS.md)及[构建与测试](../../../apps/windows/README.md#构建与测试) |
| 资料格式、保存或迁移 | [共享契约](../../../Compatibility/README.md)；macOS 保存与合并见[资料指南](../../../docs/本地资料保存与统一.md)，Windows 见[资料兼容](../../../apps/windows/README.md#资料兼容) |
| 用户操作、权限或 AI 边界 | 从[macOS 使用指南索引](../../../docs/使用指南与权限.md#按需查阅)进入有关章节；Windows 见其[功能与边界](../../../apps/windows/README.md#功能与边界) |
| 选择验证（含文档 / skill） | [验证选择](../../../CONTRIBUTING.md#验证选择)，再按需要进入平台、契约或工作流检查 |
| 交付功能、修复或改进 | [跨端跟进](../../../docs/双端协作维护.md#跨端跟进)：适用判断、查重、来源、指派及失败处理；纯文档等例外记录原因即可 |
| 提交或创建 PR | [完成开发](../../../CONTRIBUTING.md#完成开发)及 [PR 模板](../../../.github/pull_request_template.md)，核对验证证据和实际交付结果 |
| CI 或安装包问题 | [CI 与打包](../../../docs/发布流程.md#ci-与打包)及当前[工作流](../../../.github/workflows/ci.yml)，再定位相关脚本 |
| 版本与发布准备 | [发布一个新版本](../../../docs/发布流程.md#发布一个新版本)；排查失败时读取同文的[失败后重跑](../../../docs/发布流程.md#失败后重跑) |

先用标题或搜索定位，再读取当前章节；不要把表格当作逐篇必读清单。任务转入新阶段时补充所需规范，发布记录用于对应版本的变化和验证范围。

修改规则时更新所属专题及受影响的链接；保持此入口只负责路由，不复制完整流程、成员核验命令或发布清单。
