# 番茄小记 v1.6.0

应用版本 **1.6.0**：macOS build 12，Windows 1.6.0.0。本版首次同时提供 macOS 与 Windows 客户端。

## 新增与改进

- **Windows 桌面客户端**：提供 Windows 10 / 11 x64 原生 WPF 应用，包含番茄钟、待办、浮动便签、历史统计、前台 App 投入、备份、AI 模型连接与回顾、系统托盘和全局快捷键。安装包自带 .NET 8 运行时。
- **跨端资料兼容**：Windows 可读取 v1–v4 资料并写入 v4 格式，未知字段和 macOS 专属字段会保留。可通过备份迁移资料，不会自动同步；Keychain 密钥需在 Windows 重新填写。
- **白名单复选清单**：应用和网页可以直接勾选，实时更新待确认选择；“全选”只作用于列出的网页。AI 推荐、手动网站、常用名单和 AI 关闭授权默认收在“更多选项”。根据本轮白名单可自动生成学习名称，网络和学习辅助工具也会得到更合适的推荐。
- **热力图与便签优化**：修正热力图星期栏布局、格子尺寸和主题色阶，避免月份标签重叠；悬停提示更快出现并减少切换动画。便签列表和桌面便签可导出保留原文与换行的 UTF-8 TXT，中文正文使用宋体。
- **界面与发布维护**：统一页头图标，精简说明文字，修复资料库说明弹窗导致主面板收起的问题。CI 分开运行双端测试编译与按需打包，Release 同时校验两端版本并生成 Windows x64 安装器。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.6.0-macOS-universal.dmg` | macOS 安装，包含 Apple Silicon 与 Intel |
| `TomatoNotes-v1.6.0-macOS-universal.zip` | macOS ZIP 备选安装包 |
| `TomatoNotes-v1.6.0-Windows-x64-setup.exe` | Windows x64 自包含安装程序 |
| `INSTALL.txt` | macOS 离线安装说明 |
| `WINDOWS-INSTALL.txt` | Windows 安装、快捷键和资料位置 |
| `SHA256SUMS.txt` | 所有安装包的 SHA-256 校验值 |

Windows 暂不包含 macOS 专属的 Liquid Glass、合盖策略和依赖 AppleScript 的 Chrome 页面守护。Windows 与 macOS 的资料可通过备份迁移，但不会自动同步。Windows 安装程序未使用 Authenticode 商业签名；macOS 应用采用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证。

## 资料兼容与升级

macOS 继续使用 v4 资料格式，读取旧资料前会先备份。Windows 支持 v1–v4 资料并写入 v4。两端日常资料各自保存在本机，迁移前请先备份；不要让两台电脑同时写入网络共享目录。
