# 番茄小记 v1.3.2

应用版本 **1.3.2（build 9）**。本次修复分发校验，并规范后续开发流程；原有番茄钟、待办、便签、AI 回顾与专注守护继续保留。

## 修复与改进

- v1.3.1 的中文下载附件名被 GitHub 改成 `default.txt`，导致完整 SHA-256 校验清单与实际下载文件名不一致。本次将下载附件固定为 `INSTALL.txt`，DMG 内继续保留中文“安装说明.txt”。
- 发布流程在公开 Release 前核对服务器实际附件名，避免上传成功但文件名不匹配。
- 建立 main 稳定发布、develop 集成、huangzx 功能分支的 PR 流程；加入命名 / 目标分支检查、PR 模板、本地推送拦截和开发说明。

## 下载

支持 **macOS 14+**，Universal 包同时包含 **Apple Silicon / Intel**。

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.3.2-macOS-universal.dmg` | 打开后拖入 Applications，推荐 |
| `TomatoNotes-v1.3.2-macOS-universal.zip` | 解压后移动到“应用程序” |
| `INSTALL.txt` | 离线安装、权限、费用和备份注意事项 |
| `SHA256SUMS.txt` | 核对下载完整性 |

升级前正常退出旧版，建议先在设置中备份资料。当前仍为 ad-hoc 签名，**没有 Developer ID 签名或 Apple 公证**；首次打开参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 权限与注意事项

- 基础计时、待办、便签和 App 时长记录不要求辅助功能或完全磁盘访问。
- 通知按需允许；Chrome 页面白名单需要自动化 → Google Chrome；仅本轮允许 AI 关闭标签时才需要屏幕录制。
- AI 使用个人 DeepSeek Key，按服务商计费。自动总结与定时日报默认关闭，日报可能先调用多轮总结。
- 白名单默认本轮有效，沿用开关默认关闭；AI 关闭授权不沿用。无痕窗口不读取或关闭，其他 App 仅提醒。
- Chrome 截图为整个当前窗口，可能包含可见私人信息；不采集音频、不保存截图。AI 不确定或系统失败时保留页面。
- 本次发布没有完成 Chrome 截图 / 自动关闭等系统交互的端到端人工验收。规则测试不替代系统授权、通知、多屏与真实界面验证。
- 当前私有仓库的计划不支持服务端分支保护，已落实的 CI / 本地 hook 不能替代服务器强制限制；仓库保持私有。

详细说明见 [使用指南与权限](https://github.com/huangzx8090/tomato-notes/blob/v1.3.2/docs/使用指南与权限.md)、[开发与分支约定](https://github.com/huangzx8090/tomato-notes/blob/v1.3.2/CONTRIBUTING.md)。

发布流水线执行 58 项模拟接口与规则测试、Universal 构建、签名、ZIP 执行位、DMG 与 SHA-256 校验。基础功能不需要 AI Key，测试也不消耗真实 Key。
