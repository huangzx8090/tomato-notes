# 番茄小记 v1.3.1

把时间留给在意的事，也让每一段投入留下痕迹。

这是项目的首个 GitHub Release，包含此前已合并的功能与本次待办删除改进。应用内部版本：**1.3.1（build 8）**。

## 这一版有什么

- 原生菜单栏番茄钟：暂停、继续、提前结束、短休息与长休息，仿真旋钮调节时长。
- 无需每轮填写的进展卡：自动关联目标、真实投入、专注期间完成的待办；可选 DeepSeek 图文成果总结与每日定时回顾。
- 独立的纸感待办清单：完成反馈、进度环、完成印章；新增常驻删除按钮、右键删除、连续逐条撤销。
- 今日便签与历史入口：历史原稿可继续使用，自动建立今天的副本。
- Chrome 专注守护：本轮白名单、本机停留提醒，可在本轮单独授权 AI 判断后关闭明确无关的普通标签。
- 暖纸背景、深色模式、可关闭的按钮玻璃效果；macOS 26+ 使用 Liquid Glass，旧系统回退。

## 下载与安装

支持 **macOS 14+**；一个 Universal 包包含 **Apple Silicon 与 Intel** 两种架构。

| 附件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.3.1-macOS-universal.dmg` | 推荐：打开后拖入 Applications |
| `TomatoNotes-v1.3.1-macOS-universal.zip` | 直接解压后移动到“应用程序” |
| `SHA256SUMS.txt` | 校验下载完整性 |
| `安装说明.txt` | 无需打开仓库即可阅读的安装、权限和数据说明 |

升级时先正常退出旧版再替换，资料默认保留；建议提前在设置中备份。

**当前为 ad-hoc 签名，尚无 Apple Developer ID 签名和公证。** 若系统阻止打开，请确认来源及校验值，参照 [Apple 官方首次打开说明](https://support.apple.com/zh-cn/102445)。

## 权限与 AI 使用

- 基础计时、待办、便签、App 时长记录不需要辅助功能或完全磁盘访问。
- 通知按需允许；Chrome 白名单需要 **自动化 → Google Chrome**。
- 只有本轮允许 AI 关闭标签时才需要 **屏幕录制**；只截取当前普通 Chrome 窗口，不录音、不保存截图。
- AI 需要自行配置 DeepSeek API Key，按服务商规则计费。自动总结与定时日报默认关闭；日报可能先调用多轮总结。
- 白名单默认本轮有效，沿用开关默认关闭；AI 关闭授权始终逐轮选择。无痕窗口不读取，其他 App 不自动退出。

完整说明与排查步骤见 [使用指南与权限](https://github.com/huangzx8090/tomato-notes/blob/v1.3.1/docs/使用指南与权限.md)。

## 验证范围与已知限制

发布流程执行 **58 项规则与接口测试**，构建 Universal 安装包，校验签名、ZIP 解包后的执行位、DMG 完整性与 SHA-256。接口测试使用模拟响应，不消耗真实 API Key。

Chrome 自动化、系统通知、截图权限、全屏多屏及真实玻璃动效仍受目标系统影响，自动化测试不替代这些实机流程。当前 Chrome 截图与自动关闭未完成本次发布的端到端人工验收。AI 判断存在误差，建议先用没有重要未提交内容的测试标签体验；可尝试 `Command + Shift + T` 恢复误关标签。

定时任务需要应用运行；应用退出或电脑睡眠时不执行。数据保存在本机，目前没有账号、云同步或自动更新器。
