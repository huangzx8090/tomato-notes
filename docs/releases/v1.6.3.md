# 番茄小记 v1.6.3

应用版本 **1.6.3**：macOS build 15，Windows 1.6.3.0。本版修复 v1.6.2 Windows 安装包安装后无法显示主窗口的问题，并新增 macOS 系统专注模式联动。v1.6.0、v1.6.1、v1.6.2 标签保持不变。

## 修复

- **Windows 端启动后无窗口**：v1.6.2 的 Windows 安装包双击后进程存在，但主窗口、托盘图标和资料目录均不出现，也不报错。原因是 `App.xaml` 缺少 `Startup` / `Exit` 事件接线，初始化代码从未执行；接线后进一步暴露出主界面只读属性上的 `TwoWay` 绑定异常，本次一并修正。修复后启动即显示主窗口，托盘与 `%APPDATA%\TomatoNotes` 按原设计工作。
- Windows 启动异常时把完整堆栈写入 `%TEMP%\tomato-crash.log`，便于排查；保留原有提示对话框行为。

## 新增

- **macOS 系统专注模式联动**：在「提醒与快捷键」中可安装并配置系统快捷指令，选择要联动的 Focus 模式（勿扰、工作、睡眠或自定义）。专注计时运行时启用所选模式，暂停、结束或退出应用时关闭。偏好保存在本机 UserDefaults，不改变共享资料格式。安装前会说明快捷指令签名会把副本发送给 Apple 验证，仅在用户确认后签名。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.6.3-macOS-universal.dmg` | macOS 安装，包含 Apple Silicon 与 Intel |
| `TomatoNotes-v1.6.3-macOS-universal.zip` | macOS ZIP 备选安装包 |
| `TomatoNotes-v1.6.3-Windows-x64-setup.exe` | Windows x64 自包含安装程序 |
| `INSTALL.txt` | macOS 离线安装说明 |
| `WINDOWS-INSTALL.txt` | Windows 安装、快捷键和资料位置 |
| `SHA256SUMS.txt` | 所有安装包的 SHA-256 校验值 |

Windows 安装程序未使用 Authenticode 商业签名；macOS 应用采用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证。仓库维持私有，下载需要相应访问权限。

## 资料兼容与验证范围

macOS 与 Windows 使用兼容的 v4 资料格式，可通过备份迁移，不提供自动同步。两端资料各自保存在本机；迁移前请备份，不要让多台电脑同时写入网络共享目录。v1.6.2 的 Windows 端因启动缺陷未能创建资料目录，升级到本版后按正常首次启动初始化，不涉及资料迁移。

发布工作流会运行规则与模拟接口测试，构建并校验 macOS Universal 包和 Windows x64 安装器，上传完成后核验附件名与 SHA-256。自动化测试、双端编译和安装包校验**不代表** Windows 实机界面、托盘、通知、快捷键、安装卸载流程，或 macOS Chrome 授权、截图、自动关闭、系统专注模式签名与切换均已完成实机验收。本版 Windows 启动修复的实机结论来自提交者自测，发布后仍建议在目标机器上确认主窗口与托盘正常。
