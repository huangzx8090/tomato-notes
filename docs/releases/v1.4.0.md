# 番茄小记 v1.4.0

应用版本 **1.4.0（build 10）**。本次统一日常资料与计时实例，加入分类设置、多服务商模型选择、常用白名单和白名单外应用时长。

## 新增与改进

- **本机资料统一保存**：普通打开应用或其副本时，共用固定资料库和正在运行的计时实例。面板可查看保存位置和备份；显式测试模式显示独立资料提示，并支持保存后打开共用资料。
- **分类设置与引导**：六个设置分类、三步使用指南、常用节奏、未保存离开保护与 Command + , 设置入口。保留四个原有调时旋钮及拖动、方向键和加减操作。
- **AI 服务商与模型列表**：预设服务商和自定义 OpenAI 兼容接口，保存 Key 后获取可用模型并从下拉框选择。保留旧 DeepSeek 钥匙串条目的读取兼容；服务商是否支持图片和具体模型，以实际接口能力为准。
- **白名单选择**：Chrome 标签按网站分组、已选规则胶囊总览，以及跨轮次常用名单保存和导入。AI 关闭授权仍需每轮主动选择。
- **白名单外应用时长**：设置了白名单的轮次会累计并在进展、历史与通知中显示，暂停不计入；暂停状态的菜单栏图标改为播放三角形。

## 升级与资料兼容

- 资料格式升级为 **v3**；读取旧资料时先备份，再迁移。升级前仍建议在“设置 → 数据与隐私”手动备份，并正常退出旧版后替换应用。
- 日常目录为 `~/Library/Application Support/TomatoNotes/`。普通启动验证包也共用此目录；只有显式 `--ui-test` / `--data-dir` 才隔离。旧独立资料保留原位，不自动混入测试记录，见[本地资料保存与统一](https://github.com/huangzx8090/tomato-notes/blob/v1.4.0/docs/本地资料保存与统一.md)。
- 回退旧版应用前，需要恢复旧版兼容的整份 JSON 和图片备份；旧应用不能写入 v3 资料。备份不包含钥匙串 Key。
- 白名单外时长按应用粒度统计；Chrome 有页面白名单时视为白名单应用，该数值不等同于逐页分心时长。纯计时且没有白名单的轮次不显示此项。

## 安装包

支持声明为 **macOS 14+**，Universal 包包含 **Apple Silicon / Intel**。

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.4.0-macOS-universal.dmg` | 打开后拖入 Applications |
| `TomatoNotes-v1.4.0-macOS-universal.zip` | 解压后移动到“应用程序” |
| `INSTALL.txt` | 离线安装与权限说明 |
| `SHA256SUMS.txt` | 下载完整性校验 |

当前采用 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证。费用与服务端资料处理以所选 AI 服务商政策为准；本地基础功能无需 Key，也未新增账号、云同步或排行榜。

## 验证范围

- 集成代码的 **78 项规则与模拟接口测试**通过；CI 验证 Universal 构建、签名、ZIP 执行权限、DMG 与 SHA-256。
- 已分别检查设置分类与旋钮保留、未保存提示，以及独立资料的重复启动和切换共用资料流程。
- 未对各家真实 AI 服务商的图文请求、Chrome 截图 / 自动关闭、通知与所有系统授权做本次端到端验收。规则测试和构建成功不替代这些实机流程。

更多操作见[使用指南与权限](https://github.com/huangzx8090/tomato-notes/blob/v1.4.0/docs/使用指南与权限.md)和[更新记录](https://github.com/huangzx8090/tomato-notes/blob/v1.4.0/CHANGELOG.md)。
