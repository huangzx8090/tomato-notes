# 番茄小记 v1.6.1

应用版本 **1.6.1**：macOS build 13，Windows 1.6.1.0。本版承接 v1.6.0 的双端功能与产品改进，并修复 Windows 发布校验问题。远程 `v1.6.0` 标签保持不变；它此前没有对应的 GitHub Release。

## 修复

- Windows 发布工作流在检出步骤不保留 Git 凭据时，仍运行 `git fetch origin main`，导致标签、版本和主分支校验前认证失败。本版移除了冗余 fetch；检出步骤已获取完整历史，校验脚本直接检查标签提交是否属于 `origin/main` 历史。
- 本版包含 v1.6.0 的 macOS 与 Windows 客户端功能；逐项功能、兼容性与使用限制见 [v1.6.0 发布说明](v1.6.0.md)。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.6.1-macOS-universal.dmg` | macOS 安装，包含 Apple Silicon 与 Intel |
| `TomatoNotes-v1.6.1-macOS-universal.zip` | macOS ZIP 备选安装包 |
| `TomatoNotes-v1.6.1-Windows-x64-setup.exe` | Windows x64 自包含安装程序 |
| `INSTALL.txt` | macOS 离线安装说明 |
| `WINDOWS-INSTALL.txt` | Windows 安装、快捷键和资料位置 |
| `SHA256SUMS.txt` | 所有安装包的 SHA-256 校验值 |

Windows 安装程序未使用 Authenticode 商业签名；macOS 应用采用 ad-hoc 签名，未进行 Developer ID 签名或 Apple 公证。仓库维持私有，下载需要相应访问权限。

## 资料兼容与验证范围

macOS 与 Windows 使用兼容的 v4 资料格式，可通过备份迁移，不提供自动同步。两端资料各自保存在本机；迁移前请备份，不要让多台电脑同时写入网络共享目录。

发布工作流会运行规则与模拟接口测试，构建并校验 macOS Universal 包和 Windows x64 安装器，上传完成后核验附件名与 SHA-256。自动化测试、双端编译和安装包校验不代表 Windows 实机界面、托盘、通知、快捷键、安装卸载流程，或 macOS Chrome 授权、截图与自动关闭均已完成实机验收。
