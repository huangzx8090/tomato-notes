# 番茄小记 v1.5.0

应用版本 **1.5.0（build 11）**，发布于 2026-10-24。本次加入专注热力图、历史搜索、待办手动结转、AI 白名单推荐与默认关闭的 AI 自动记录，并更新柔和立体番茄图标。

## 新增与改进

- **专注热力图**：今日页展示最近 13 个自然周，“查看全部”打开可调整大小的 53 周窗口，并可翻阅更早历史。每周一列、周一至周日排列；悬停显示日期、星期和准确时长，点击可查看当天记录。使用固定色阶，只累计保存的真实番茄专注秒数，提前结束仍保留，暂停、休息和普通活动时长不混入。
- **本地历史搜索**：今日页搜索入口与应用主界面的 Command + F，支持待办、原始便签、专注目标、用户成果及已有 AI 总结。支持多关键词、类型和日期筛选；打开原记录，区分用户记录与 AI 总结，不调用 AI 或识别图片。
- **手动待办结转**：展开之前未完成事项，单项或批量安排到今天；保留原任务 ID、创建日和完整安排历史。进入今天后可修改、完成或作为专注目标，未完成时可撤销本次安排。历史日继续显示原安排，完成数按实际完成日期统计。
- **AI 白名单推荐**：根据本轮目标读取当前 App 与所有普通 Chrome 窗口的网页，逐项给出推荐和理由，由用户选择确认，保留手选规则。候选只发送名称、清理后的标题和网站，完整页面地址留在本机。
- **可选 AI 自动记录**：在“设置 → AI 助手”主动开启，按所选来源记录 Chrome 前台普通页面标题和网站、便签变更与完成待办，积累材料后识别主题，结束后后台整理。可补充文字、改名、查看及删除依据，同主题轮次可合并展示。暂停、休息、锁屏时停止采集，不自动截图或关闭标签。
- **集成修复**：标题内嵌 URL 会在外发前清理；更换 AI 服务商、地址或模型会取消并失效旧守护请求，客户端与凭据保持对应。完成事件在相邻轮次和午夜分段只计一次；删除活动使相关总结失效时，历史搜索同步刷新。

## 升级与资料兼容

- 资料格式升级为 **v4**，共同保存活动记录和待办安排历史。读取旧资料时先保存原始备份；旧待办缺少安排历史时沿用原始日期，AI 自动记录默认关闭。
- 升级前建议在“设置 → 数据与隐私”手动备份，正常退出旧版后替换应用。日常目录仍为 `~/Library/Application Support/TomatoNotes/`；普通打开应用复用本机资料库和已有计时实例。
- **v1.4.0 等旧版无法读取 v4**。回退前需恢复旧版兼容的整份 JSON 和关联图片备份；备份不含钥匙串 Key。资料合并保留新增字段，相同 ID 的歧义内容会报错。
- AI 自动记录与回顾会将用户选择的材料发送给当前服务商，可能产生费用；文字本身仍可能含私人信息，应按需选择来源。Chrome 自动记录需要自动化权限，屏幕录制仍只用于逐轮授权的守护截图核对。

## 安装包

声明支持 **macOS 14+**，Universal 包包含 **Apple Silicon / Intel**。

| 文件 | 用途 |
| --- | --- |
| `TomatoNotes-v1.5.0-macOS-universal.dmg` | 打开后拖入 Applications |
| `TomatoNotes-v1.5.0-macOS-universal.zip` | 解压后移动到“应用程序” |
| `INSTALL.txt` | 离线安装、权限与升级说明 |
| `SHA256SUMS.txt` | 下载完整性校验 |

当前采用 ad-hoc 签名，尚未使用 Developer ID 或 Apple 公证。仓库维持私有，下载需要相应访问权限。
