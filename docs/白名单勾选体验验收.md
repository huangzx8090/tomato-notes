# 白名单勾选与热力图悬停

开发分支 `feat/whitelist-checkbox-flow` 从 `origin/develop` 的 `9c8b0e6` 建立，不更改资料格式或应用版本。

## 操作变化

- 设置窗口默认只显示本轮目标、应用复选清单、Chrome 网页复选清单和“更多选项”。页面直接展开，勾选 / 取消使用同一个控件。
- 网页按地址规范化去重，保留不同查询条件的课程或视频；同名网页显示本机地址作区分。搜索后的“全选”仅作用于列出的已打开页面，不扩大成整站规则。
- 旧整站规则保持兼容。取消某一网页时，移除覆盖它的整站规则，并将其余当前已允许网页保留成精确选择；当前未打开的已保存网页走同一条取消路径。
- AI 推荐与手选显示在同一清单中。手动修改先保留当前有效草稿，再取消旧请求，防止 AI 结果重新加入已取消的条目；计时和执行计划仍只在确认按钮处更新。
- AI 推荐、常用网页、手动网站和 AI 关闭授权放在默认折叠的“更多选项”。AI 关闭保留原权限校验、当轮授权与启用提示。
- 无选择、目标未填、Chrome 未读取或 AI 权限不足时，底部直接提示无法确认的原因；“仅计时”仍可使用。
- 热力图人工悬停等待从 350ms 缩短到 60ms，提示切换禁用动画；去掉重复系统 help，保留旧任务取消、未来禁用、移出 / 翻页 / 销毁清理。60ms 是代码设定的等待，不是实测端到端显示耗时。

## 实际操作待验

继续遵守暂停自动实机验证的要求；打开预览供用户查看不代表以下操作已由代理点击验收：

1. 热力图停留、快速跨格、移出和翻页时提示准确，没有迟到提示；实际端到端出现速度待用户体验。
2. 应用 / 网页用鼠标与键盘反复勾选、取消、搜索后全选，显示与最终本轮计划一致。
3. 推荐加载中或完成后手动取消，旧结果不会重新勾选；关闭窗口或仅计时不应用草稿。
4. 旧整站计划取消单个已打开 / 未打开页面，其余当前页面保留，取消页重新打开也不再允许。
5. 更多选项默认折叠，常用导入、手动网站和 AI 关闭授权仍可按需使用；权限错误有明确提示。

构建与规则测试、离屏静态预览和真实 Chrome / AI / 截图 / 关闭行为分别报告。
