# AI 白名单推荐

填写本轮目标后，在“更多选项 → AI 帮我勾选”中点击“读取当前 App 与网页并推荐”。番茄小记读取当前运行的普通 App 和 Chrome 所有普通窗口里的 HTTP(S) 网页，由设置中当前选择的 AI 服务商逐项给出建议。

## 确认流程

1. 填写本轮目标，或从今天未完成的待办选择。
2. 点击推荐按钮；Chrome 正在运行时，首次使用需要允许自动化读取。Chrome 读取失败时不发送缺少网页的推荐，可重新连接或手选。
3. 查看“推荐使用”“可能需要”“不推荐”及逐项理由。仅推荐项默认勾选，其他项可展开后选择；也可一键只选推荐项或全不选。
4. 建议会同步显示在上方的应用 / 网页勾选清单。可以在同一清单补选或取消，点击窗口底部“开始专注”或“保存选择”才应用到本轮；取消或“仅计时”不会应用草稿。

手动勾选或取消会先保留当前显示的推荐选择，再取消已有推荐请求并接管草稿，防止旧建议重新加入取消的项目。修改前没有额外确认步骤，计时和本轮执行计划仍只在底部确认时改变。

网页推荐只放行具体页面，保留本机 URL 查询条件区分不同视频，AI 不能自行扩大为整个网站。相同地址在多个窗口打开时合并成一项；不同查询条件的页面分别推荐。Chrome 本身按页面守护，不作为整个应用放行。番茄小记自动允许；其他应用仍按 App 处理，只提醒，不退出。

修改目标或 AI 配置后，已有推荐作废并取消进行中的请求，需重新读取；关闭窗口也会取消请求。每次点击重新推荐都重新获取当前上下文。手选名单仍可正常使用，推荐失败不会清空手选内容。

现有“沿用上轮目标与白名单”“存为常用”继续使用最终确认的规则；推荐不会自动开启沿用，也不会授予 AI 关闭网页权限。

## 发送内容

| 内容 | 本机使用 | 发送给当前 AI 服务商 |
| --- | --- | --- |
| 本轮目标 | 保存本轮目标 | 是 |
| 当前运行的 App 名称 | 展示、选择 | 是 |
| 普通网页标题、网站 | 展示、选择 | 是 |
| App bundle ID、窗口 / 标签 ID | 映射到本轮规则 | 否 |
| URL 路径、查询参数、账号密码 | 本机页面规则规范化 | 否 |
| 页面正文、截图、浏览历史、无痕标签内容 | 不采集 | 否 |

候选使用临时 ID。标题和 App 名称作为待分析资料，不能覆盖推荐指令。服务端必须为每个已知候选恰好返回一条有效建议；新增 ID、重复、遗漏、不完整返回或非法字段均整组拒绝。真实规则仅从本机快照生成。

标题最多发送 240 字，网站最多 160 字；候选每批最多 40 项，逐批发送同一目标。全部批次通过校验后才展示结果，不自动重试。单次最多 256 批、16 MiB 文字，单批最多 128 KiB，超限明确报错，不静默只处理部分名单。页面标题可能包含私人信息，点击推荐即将这些标题发送给设置里选定的服务商。

推荐是文字能力，不需要屏幕录制权限。输入 / 输出 Tokens 在推荐卡里单独显示，实际费用以服务商为准；与专注中 AI 关闭核对的次数和用量分开。

## 验证边界

- `Scripts/test.sh`：119 项测试通过，包含 70 项 Core 和 49 项 System 测试。覆盖完整逐项校验、服务商差异、分批失败 / 取消、本机映射、隐私过滤及多窗口枚举。
- 独立 QA 资料中，真实读取当前 10 个 App、10 个不同 Chrome 网页，调用当前配置的 `deepseek-flash`，返回完整 20 项建议；本次用量为输入 934 / 输出 543 Tokens。
- 界面中取消一项推荐 App、补选一项可选 App 后确认，本轮保存的名单与所选内容一致；确认前计时保持 idle 且没有新建轮次，确认后才开始专注。随后暂停并核对本轮名单。
- 实测未开启 AI 关闭网页，未触发截图或关闭标签。本次功能的真实推荐与确认链路通过，不替代原有关闭核对流程或首次系统权限弹窗的验收。
