# 使用指南与权限

本文说明 macOS 客户端的操作、权限与隐私边界；Windows 的功能范围和操作见 [Windows 客户端说明](../apps/windows/README.md)。系统设置的中文名称可能随 macOS 版本变化；以系统实际提示为准。

热力图、历史搜索和手动待办结转均使用本机资料。AI 自动记录默认关闭，开启前请阅读下文的材料来源与发送范围。

## 1. 首次安装与升级

1. 从本仓库的 GitHub Release 下载 DMG 或 ZIP；Universal 包包含 arm64 与 x86_64 两种架构。
2. 将“番茄小记.app”放入 `/Applications`（“应用程序”）再启动，避免一直从 DMG、Downloads 或多个不同路径运行。
3. 升级前在“设置 → 数据与隐私”点“备份数据”，正常退出旧版后替换。构建或覆盖文件不会让仍在运行的旧进程自动变成新版。
4. 默认从菜单栏打开，设置可以开启 Dock 图标。Esc 收起面板，计时继续；退出应用会停止计时，重新启动后需主动继续。

### 安装包与首次打开

当前使用 ad-hoc 签名，没有 Apple Developer ID 签名和公证。签名完整性验证通过不等于 Gatekeeper 信任，也不等于 Apple 公证。

如果系统提示无法验证开发者或阻止首次打开：

- 确认来自本项目的 Release，核对附件校验值。
- 尝试打开一次，再查看 **系统设置 → 隐私与安全性** 中针对该应用的提示；确认来源可信后按提示选择“仍要打开”。
- 参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，单位管理设备可能限制此操作。

无需关闭系统 Gatekeeper 或 SIP。若系统明确提示恶意软件或文件损坏，请停止安装并重新核对来源及下载完整性。

将 `SHA256SUMS.txt` 和对应版本的附件下载到同一目录，终端中进入该目录后可校验：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

该清单同时列出 DMG、ZIP 与安装说明；只下载一个安装包时，其他文件显示缺少不代表已下载的文件校验失败，请看对应文件的结果。更简单的方式是 `shasum -a 256 文件名`，与清单中该文件的一行逐字对比。

## 2. 哪些权限需要开启

只启用自己使用的功能即可。

| 使用场景 | 权限 / 入口 | 未授权时 |
| --- | --- | --- |
| 番茄钟、待办、浮动便签、每轮本机进展卡 | 无额外隐私权限 | 正常使用 |
| 记录前台 App 名称与停留时长 | 应用内“前台 App 记录”开关，不需屏幕录制 | 开关关闭后对应时间归入“未记录” |
| 阶段结束等系统通知 | 系统设置 → 通知 → 番茄小记 | 记录和计时保留，无系统横幅 |
| Chrome 普通窗口标签选择、AI 白名单推荐和守护 | 系统设置 → 隐私与安全性 → 自动化 → 番茄小记 → Google Chrome | 无法读取和控制 Chrome 标签 |
| AI 自动记录中的 Chrome 浏览材料 | 设置 → AI 助手 → AI 自动记录 → 允许读取 Chrome；使用上述自动化权限 | 网页材料不记录，计时与其他允许的来源继续 |
| 本轮允许 AI 核对后关闭标签 | 隐私与安全性 → 屏幕录制，或屏幕与系统音频录制 | 无截图，不执行 AI 自动关闭 |
| 保存 / 读取 AI 服务商 Key | macOS 钥匙串可能询问 | 读取失败时 AI 不可用，本地功能继续 |
| 主动选择成果图片 | 系统文件选择器；文件所在位置须可访问 | 不能导入选中的文件 |

**不需要辅助功能、输入监控、完全磁盘访问、摄像头或麦克风权限。** 不读取键盘输入、剪贴板历史或照片图库，不需要授予照片权限。上传图片是用户从文件选择器主动选择，不会扫描相册。

### 通知

- 首次开始或在设置中点“通知权限 / 测试提醒”时，按系统提示允许。
- 在 **系统设置 → 通知 → 番茄小记** 调整横幅等呈现方式，另检查系统“专注模式 / 勿扰”。
- “一次提示音”是应用内独立选项；关闭系统通知不等同于关闭这个声音开关。
- 允许通知不保证每种系统状态都出现横幅，实际呈现仍由 macOS 控制。

### 专注时启用系统专注模式

1. 打开 **设置 → 提醒与快捷键**，点击“安装专注模式快捷指令”。
2. macOS 会打开“快捷指令”并显示添加确认；点击“添加快捷指令”后，应用会自动检测并连接。
3. 点击“配置所选专注模式”，分别为快捷指令里的开启和关闭动作选择同一个模式，例如勿扰、工作、睡眠或自定义模式。
4. 回到设置，自行选择是否开启“专注运行时启用所选模式”。

安装前，应用会说明 macOS 签名流程：签名时快捷指令副本会发送给 Apple 验证。本应用使用“任何人”模式，不附带联系人信息；不会读取其他快捷指令的内容。用户确认后，还需在“快捷指令”中点击“添加快捷指令”。

启用后，开始或继续专注时会启用所选模式，暂停、结束或退出应用时会关闭。快捷指令不记录此前的专注状态，原先已开启的模式不会恢复。应用只查询快捷指令名称和 ID 来识别自己创建的项目。

### Chrome 自动化

1. 打开 **Google Chrome 的普通窗口**，不要使用无痕窗口做首次连接。
2. 在 **专注 → 专注范围** 中读取 Chrome 网页，允许番茄小记控制 Google Chrome。
3. 若之前拒绝，在 **隐私与安全性 → 自动化** 中找到番茄小记，开启 Google Chrome；回到应用重新连接。
4. 系统列表通常在应用尝试请求后才出现；没有列表项时，先在应用内触发连接。

通过 Chrome 内置 Apple Events 接口读取普通窗口标签的标题、URL 与标识；白名单推荐可读取所有普通窗口，自动记录只采样前台普通标签。不读取浏览历史，不向网页注入脚本。**无需 Chrome 扩展，也无需打开 Chrome 的“允许来自 Apple 事件的 JavaScript”。** 当前只支持 `com.google.Chrome`，不把 Edge、Safari 或其他 Chrome 变体视作已支持。

### 屏幕录制

1. 先在“设置 → AI 助手”配置服务商与支持图文输入的模型，并连接 Chrome 自动化。
2. 在本轮守护中勾选 **允许 AI 确认后关闭无关 Chrome 标签页**，点 **允许关闭前读取 Chrome 窗口**。
3. 按系统提示在隐私设置中开启番茄小记的屏幕录制；系统要求退出重新打开时，请先保存并正常退出再打开。
4. 返回应用点“刷新权限”，重新为当前轮次确认守护设置。

该权限只用于关闭前的最后核对。请求截图时选择当前普通 Chrome 窗口，不持续录屏、不采集系统音频，截图在内存中处理，不写本地文件。**窗口截图可能包含工具栏、其他标签标题及窗口内可见的私人资料**，不是仅裁切网页正文；请在本轮允许前确认可接受这一范围。

授权本身不保证截图成功；多窗口匹配不唯一、系统捕获失败或权限状态异常时会保留页面。只需要本机提醒时不用开启屏幕录制。

### 钥匙串与升级后的权限

填写 Key 后保存在本机钥匙串。读取时若 macOS 询问，请核对应用名称和安装来源；应用不会要求把钥匙串密码填写进自身界面。

当前包没有稳定的 Developer ID 身份。替换版本、切换正式 / 验证包或改变路径后，系统可能重新询问自动化、截图或钥匙串权限；旧授权是否继续有效以系统当前状态为准。优先固定从“应用程序”启动，按上述入口重新连接或授权。

## 3. AI：什么时候发送什么

在“设置 → AI 助手”选择服务商并保存自己的 Key，获取模型列表后从下拉框选择；自定义服务商需填写 OpenAI 兼容接口地址。图片总结与 Chrome 核对需要支持图文输入的模型。基础功能无需 Key；费用、额度和服务端资料处理以所选服务商政策为准。

| 触发方式 | 发送的内容 | 自动行为 |
| --- | --- | --- |
| 测试连接 | API 鉴权并请求模型列表，无总结材料 | 不生成成果，不证明图文总结链路已通过 |
| AI 白名单推荐 | 本轮目标、当前运行的 App 名称和普通 Chrome 网页的标题、网站 | 主动点击后请求，建议须确认才应用 |
| AI 起名 | 已勾选 App 的名称、网页标题和网站 | 勾选后可自动生成，也可手动请求；手写名称优先 |
| 本轮 / 当天手动总结 | 选定范围的目标、投入、App 名称与时长、待办、描述和关联成果图片 | 用户点击后执行 |
| 结束后自动总结 | 新结束且投入至少 60 秒的轮次材料 | 默认关闭；每轮仅自动尝试一次，不扫描历史，失败不反复重试 |
| AI 自动记录 | 授权来源的页面标题、网站、便签变更、完成待办和可选 App 辅助信息 | 默认关闭；约两分钟识别主题，按新材料有限次更新，结束后自动尝试一次回顾 |
| 每日定时回顾 | 当天材料与各轮已有总结；必要时先解析未总结或已修改轮次的图片和描述 | 默认关闭；每天一次定时尝试，可能包含多个请求 |
| 守护最后核对 | 本轮目标、网站、当前标题及当前 Chrome 窗口截图 | 必须本轮另行授权，提醒并再等待后才调用 |

- 只写目标、编辑描述、导入图片或勾选待办，不会立即发起 AI 总结。
- 开启 AI 自动记录后，本轮新增材料可在后台参与随后的主题识别；其开关已包含结束回顾。关闭它会停止采集，旧的自动回顾与日报仍按各自开关运行。
- 自动每轮总结与定时日报互相独立。关闭一项不代表另一项也关闭；关闭自动选项不撤回已经发出的请求，也不删除现有结果。
- 成果图片导入后留在本机 `Attachments/`；最多 6 张，每张原文件最多 25 MB，导入时转为最长边 1600 像素内的 JPEG。原始文件不被修改；上传的是处理后的副本。
- 守护截图不转为成果附件、不落盘；发送元数据时不带完整 URL 路径和查询参数，但图片和标题自身仍可能含敏感信息。
- 本地不保存截图不代表服务商不会处理或留存请求。服务端政策由所选服务商决定，敏感材料请先裁剪或遮挡，再主动选图。
- 自动生成失败不覆盖已有总结。手动重新生成会再次消耗额度；多轮日报的次数通常超过一次。
- 守护默认每轮最多 3 次判断，可设置 1–5 次；达到上限后只提醒。界面用量来自服务端返回，失败请求的计费以服务商为准。
- AI 内容可能不准确。App 时长不证明任务完成或知识掌握；图片中的可见成果也需要本人核对。

### AI 自动记录

1. 在“设置 → AI 助手”配置服务商和文字模型，在“AI 自动记录”中选择允许的来源并开启总开关。
2. 使用 Chrome 材料时，主动点击“允许读取 Chrome”。它使用自动化权限，不需要屏幕录制；记录开关与专注守护分别控制。
3. 直接开始专注，可不填目标。约两分钟且材料足够后识别主题；投入至少一分钟后结束，AI 在后台整理，本机计时与材料先保存。
4. 进展卡可“补一句”，详情可修改主题、查看原始活动或删除材料；明确关联到同一主题的轮次可在今日页合并查看。

| 允许的来源 | 保存和发送的材料 | 限制 |
| --- | --- | --- |
| Chrome 普通前台页面 | 清理后的标题、网站、专注时间分段和采样停留秒数 | 约 5 秒采样；切换边界可能漏记，不能视为精确阅读时间 |
| 本轮便签变更 | 新写入或修改的文字片段，最长 1200 字 | 不把旧便签全文作为本轮材料 |
| 本轮完成待办 | 专注运行中完成的文字与时间 | 暂停或休息中的操作不归入本轮 |
| App 辅助信息 | 前台 App 名称和时长 | 需同时开启 App 明细记录；名称与时长不能证明完成了具体任务 |

只在专注运行且未锁屏时采集，暂停、休息、睡眠和退出时停止，不补记空档。不读取无痕标签、内部页、`file:` 页面、网页正文、浏览历史、编辑器内容、键盘或剪贴板，也不自动截图。URL 路径、查询参数和窗口 / 标签标识不保存到活动资料；标题和用户文字自身仍可能包含私人信息。

进行中最多 4 次主题识别；有新材料且距上次已累计至少 5 分钟专注才会再次识别。结束时有新材料可再识别一次，然后自动尝试一次回顾；同一批失败材料不反复请求。手动名称优先，不根据单纯的 App 时长推断已读完、学会或完成任务。

关闭总开关后停止新增采集和主题识别，保留已有本机材料，已发出的请求无法撤回。自动记录已包含结束回顾，无需重复开启旧的每轮自动总结；每日回顾仍按自己的开关运行。没有 Key 时可先保存本机活动，不会后台扫描补跑历史轮次。

删除活动会删除该轮同一来源的分段并清除依赖的轮次与当日日报总结，不会删除原便签、待办或浏览器标签。原始活动支持轮次级查看，尚不支持每条 AI 结论逐项跳转依据。

### AI 成果回顾

每轮进展卡由本机记录生成，不需要 Key。需要 AI 时，在进展详情展开“补充一句或图片（可选）”，填写描述或选择图片，再点击“让 AI 总结工作与成果”。结果按做了什么、取得的成果、待继续和待确认整理，可复制、改写材料后重新生成。

目标表示计划，App 时长表示投入，具体成果需要完成待办、用户描述或图片证据。自动记录和守护截图不会替你导入成果图片。每日回顾会先整理当天尚未总结或材料已修改的轮次，再汇总全天，因此一次操作可能有多次请求。

### AI 白名单推荐与起名

在“专注 → 专注范围”填写目标，展开“更多选项 → AI 帮我勾选”，主动读取当前 App 与普通 Chrome 网页并请求推荐。学习内容和网络代理 / VPN、笔记、文件管理等辅助工具都可推荐；用途不明的项目保留待确认，不按平台名称直接排除。建议仍可能误判，可在同一清单取消或补选，点击“开始专注”或“保存选择”才应用。

推荐只发送目标、App 名称、网页标题和网站。App 标识、窗口 / 标签 ID、完整 URL 和查询参数留在本机，不发送页面正文、截图、浏览历史或无痕内容。标题自身可能包含私人信息；候选较多时分批请求，全部成功后才显示建议，失败不应用部分结果。

勾选白名单后也可让 AI 为本轮起名，或点击“AI 起名 / 重新生成”；起名只发送已选 App 名称、网页标题与网站。手动填写优先，起名不会自动开始专注。

修改目标或 AI 配置后已有推荐作废，关闭窗口会取消请求。手动调整会保留当前选择并取消旧推荐，避免旧结果重新加入已取消项。推荐与起名均不授予 AI 关闭权限，也不需要屏幕录制；推荐用量单独显示。

### Key 配置与错误排查

优先在“设置 → AI 助手”按服务商保存 Key，兼容读取旧 DeepSeek 钥匙串条目。进程环境变量优先级为 `AI_API_KEY` → `<服务商 ID 大写>_API_KEY` → 旧 DeepSeek 变量（仅 DeepSeek）→ 钥匙串；例如 OpenAI 使用 `OPENAI_API_KEY`。DeepSeek 的 `DEEPSEEK_API_KEY` 会先于旧小写 `deepseek` 读取。环境变量存在时，界面更换或移除钥匙串 Key 不会覆盖它。终端 `export` 通常不影响 Dock 启动的应用。

开发者仍可在已配置旧 DeepSeek 变量的同一个终端导入对应钥匙串，命令不会输出密钥：

```bash
swift run --package-path apps/macos TomatoDataTool import-deepseek-key
```

| 现象 | 检查方式 |
| --- | --- |
| 未配置 Key / 鉴权失败（401） | 重新保存有效 Key；确认启动环境没有旧变量覆盖 |
| 权限不足、额度或限流（403 / 429） | 查看服务商账号、额度和限制；不要连续重复点击 |
| 网络 / 超时 / 服务错误 | 核对服务商与自定义接口地址、网络，稍后手动重试；旧记录和旧总结保留 |
| 测试连接成功但总结失败 | 连接测试只验证模型接口；继续核对服务额度、模型、图片与错误提示 |
| 图片导入失败 | 核对格式、原文件大小、数量和文件访问权；HEIC 会先在本机转成 JPEG |

## 4. 白名单与自动关闭的边界

在“专注 → 专注范围”直接勾选允许的应用，读取并勾选 Chrome 网页，可按标题或网站搜索。“全选”只作用于当前搜索结果中的已打开网页。手动添加网站和常用名单在“更多选项”中；取消、关闭窗口或选择“仅计时”不会应用名单草稿。

- 白名单默认只对本次专注有效，暂停保留、结束失效。重启后的活跃计划不作为自动关闭授权恢复。
- 可选“自动沿用上轮目标与白名单”，默认关闭。开启后名单会保存并用于新一轮；关闭开关清空保存名单。**AI 关闭授权始终不沿用**。
- Chrome 用页面规则判断，其他 App 用 App 规则判断；番茄小记自动放行以方便待办和便签操作。
- 页面按网站分组，可保存并导入常用白名单。白名单外时长按应用粒度累计，暂停不计入；Chrome 有页面规则时视为白名单应用，该时长不等同于逐页分心时长。没有配置白名单的纯计时轮次不显示该项。
- “此页”保留查询参数，适合同一视频网站中的具体课程；“网站”覆盖该域名与子域名，会同时放行这个网站里的其他内容。
- 默认离开白名单 60 秒提醒，再等待 60 秒才可能 AI 核对；最短分别为 5 秒。切换 App / 标签、返回白名单或暂停会重新计算停留。
- AI 只有明确判为无关且置信度至少 0.9 才可能关闭；关闭前重新确认轮次、运行状态、前台窗口、标签 ID、URL 与标题。
- 其他 App 只提醒，不会强制退出。无痕窗口不读取内容、不截图、不关闭；Chrome 内部页及非 HTTP(S) 页不执行 AI 关闭。
- 无法判断、页面已变、权限不足、网络或截图失败时保留标签。同一页不反复请求，编辑本轮守护也不重置已消耗次数。
- 误关可尝试 Chrome 的 **Command + Shift + T**，但未提交表单或页面临时状态可能无法恢复。重要编辑页不宜作为首次测试对象。

## 5. 记录、日期与定时

- 记录前台 App 仅在专注运行时生效；暂停、休息和退出不计入。只记录 App 名称与时长，不据此读取文档内容。
- 本地日期以运行电脑当前时区为准；跨日会拆分统计。更改时区或系统日期可能改变“今天”显示范围，历史并未因此删除。
- 热力图沿用保存的专注分段日期，不因当前时区重新划分历史。今日页显示 13 周；“查看全部”显示并翻阅 53 周。悬停显示时长，点击切换日期或查看当天记录。
- 今日页搜索图标或应用主界面的 Command + F 可搜索本地待办、原便签、目标和成果，支持类型与日期筛选。搜索打开原便签，不会触发“继续使用”或生成副本。
- 锁屏、系统睡眠、重启后暂停，返回后需主动继续。合盖外接活动屏幕时的继续计时受设置与系统实际睡眠状态共同影响。
- 阶段结束不会自动进入下一阶段，避免离开电脑后一直增加番茄轮数。改时长不会重置正在进行的阶段。
- 每日定时回顾需要应用运行且解锁；应用不能在退出或系统睡眠时唤醒自己。当天错过时间后会补尝试；完成一次定时尝试后不再自动重复，失败可手动重试。
- 程序退出时未发出的自动每轮回顾队列不会下次补跑；定时日报可以按当天资料再整理。

## 6. 待办与便签

- 待办保留创建日，不自动移到下一天。待办顶部可展开之前未完成事项，单项或批量“安排到今天”，进入今天的可编辑清单；保留原任务和安排历史，不复制任务。
- 未完成时可撤销本次结转，只撤销安排，不撤销后续文字编辑。已完成事项不能直接撤销结转；历史在“今日”按日期查看，显示后续安排或完成日期，完成数计入实际完成当天。
- 勾选可撤回完成，双击改字；删除用垃圾桶或右键。底部“撤销”按删除逆序恢复原记录，关闭提示或退出后本次撤销记录清空。
- 便签默认今天；“历史便签 → 继续使用”建立今日副本并保留原稿。同一天重复继续只打开已有副本，不覆盖补写。
- 便签列表和桌面编辑器均可“导出 TXT”，通过系统保存框选择文件名与目录，导出完整 UTF-8 原文，保留换行与空白，不添加标题和日期。取消保存不写文件，导出不创建便签副本。
- 便签快捷键打开今天最近使用的便签，今天没有时新建；历史便签仍可从对应日期打开。
- 收起便签窗口会保留资料，删除便签经过确认后不能在应用内撤销。重要内容先备份。
- 只有专注运行时完成的待办才归入该轮进展；目标、暂停中完成的任务或 App 时长不会被自动冒充为具体成果。

## 7. 备份、恢复与卸载

日常资料目录：`~/Library/Application Support/TomatoNotes/`。普通打开应用副本或验证包也共用此目录，重复打开复用已有计时实例；只有显式 `--ui-test` / `--data-dir` 才隔离，面板会显示资料模式。已有独立记录不自动混入日常历史，迁移方法见[本地资料保存与统一](本地资料保存与统一.md)。

### 备份

使用 **设置 → 数据与隐私 → 备份数据**，保留生成的 JSON 和同名 `.assets/Attachments/` 文件夹。图片缺少时，文字可能仍能恢复，原图总结却无法完整重建。备份不包含钥匙串 Key，不等同于跨设备同步。

### 手动恢复

当前没有一键恢复向导。谨慎按以下顺序操作：

1. 正常退出所有使用这份资料的番茄小记实例。
2. 先把整个现有 `TomatoNotes` 资料目录复制到另一个位置留底。
3. 将选定备份 JSON 复制为正式目录的 `data.json`；将该备份同名 `.assets/Attachments/` 的内容恢复至正式目录的 `Attachments/`。
4. 重新打开应用并核对计时记录、待办、便签和图片；必要时在设置中重新配置 Key。

不要在应用运行时编辑 JSON，也不要只用旧 JSON 配上不匹配的附件。v1.5.0 将旧资料备份后迁移为 v4，保留活动记录和待办安排历史；v1.4.0 等旧版不能读取 v4。**回退旧版应用前需恢复旧版兼容的整份 JSON 和图片备份**。

### 卸载与隐私

删除应用包不会自动删除资料和钥匙串 Key。若要彻底移除，先备份，再自行清理资料目录，并在应用设置按服务商移除 Key；“钥匙串访问”中对应服务为 `com.zixuan.TomatoNotes.ai`，旧 DeepSeek 条目为 `com.zixuan.TomatoNotes.deepseek`。若曾设置环境变量，还需移除对应启动环境配置。撤销权限可在系统隐私设置完成。清理前确认不再需要历史与图片。

## 8. 常见问题

| 问题 | 建议 |
| --- | --- |
| 打开后看不到窗口 | 看屏幕顶部菜单栏；可开启 Dock 图标。相同资料目录重复启动会唤出已有实例 |
| 升级后看起来还是旧版 | 正常退出旧进程，再从“应用程序”打开替换后的版本，设置底部核对版本号 |
| 通知不弹出 | 同时检查应用通知开关、系统通知与专注模式，用“测试提醒”检查 |
| Chrome 标签列表为空 | 确认普通 Chrome 窗口正在运行，连接并检查自动化权限，在专注范围中重新读取网页 |
| 白名单明明保存了却不能用 | 区分本轮与沿用设置，检查是否新一轮、暂停或重启，以及 URL 查询参数是否变化 |
| 不能截图或自动关闭 | 检查本轮授权、目标、Key、两项权限、等待时间和每轮次数；系统截图失败时预期保留页面 |
| 计时突然暂停 | 核对锁屏、睡眠、合盖 / 外接屏策略；恢复后需要手动继续 |
| 快捷键无反应 | 在设置换键，检查第三方占用；不用为此额外开启辅助功能或输入监控 |
| 玻璃或动画没有显示 | 检查玻璃开关、系统版本、减少透明度 / 动态效果设置；暖纸背景保持不透明 |
| 资料只读或保存失败 | 先保留原始目录和错误提示，检查磁盘空间及同库实例；不要删除资料来“重置” |
