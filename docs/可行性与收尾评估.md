# 番茄小记：剩余工作、可行性与推荐方案

> 本文保留早期首版评估。后续已完成正式数据迁移、同库进程保护、快捷键独占注册，并根据用户追加需求实现 DeepSeek 文字/图片成果总结、定时每日回顾和计时旋钮。当前功能与验证状态以 [README](../README.md) 和 [AI 工作与成果回顾](AI工作与成果回顾.md) 为准；下表的旧缺口不代表当前代码仍缺少这些功能。

评估日期：2026-10-21。依据是当前源码、已打包应用、本轮实机观察、用户反馈、11 项规则测试、目标 Mac 的系统状态以及 Apple 文档与 SDK 头文件。本文件描述现状和建议，不代表未验证的系统行为已经通过。

## 结论

当前 SwiftUI + AppKit 方案能够继续完成本期 Demo。主要模块都已有代码，剩余工作集中在快捷键冲突处理、单一应用与数据收尾，以及系统行为的实机验收。推荐先完成“可长期使用的本地版”，再进入图片辅助总结和桌宠。

目前发现的明确代码缺口是快捷键冲突处理：`HotkeyManager.swift` 在 `RegisterEventHotKey` 中传入 `0`，属于非独占注册。当前 SDK 的 `CarbonEvents.h` 明确说明非独占组合允许多个应用接收同一个热键。因此，现有错误提示不能完整实现“被占用时提示换键”的需求。

此外，目前正式包与验证包分别运行，数据目录也分开，用户已在两份数据中输入内容。直接切换到默认数据目录会呈现空库，不能误以为原数据已丢失；这需要先备份、迁移和统一入口。

## 推荐执行顺序

### P0：先保护已有数据并消除确定缺口

1. 暂停并正常退出两个版本，备份两份 `data.json`。
2. 按 ID 合并用户输入和原始历史，采用正式参数；将运行中的计时恢复为暂停。迁移结果与原始数量、时长及内容核对，保留备份。
3. 统一为“番茄小记”正式包与默认数据目录，加入同库单实例保护。状态栏为默认入口；如需要 Dock 入口，应做成明确的用户设置。
4. 修正快捷键独占注册与错误回滚，完成真实占用和三个动作的验证。

### P1：完成会影响记录准确性的实机验收

1. 正常运行一轮 25 分钟，穿插两个以上 App 的切换、暂停与继续，核对专注秒数与 App、未归属、未记录秒数之和。
2. 验证锁屏、系统睡眠、普通合盖、合盖外接屏与拔屏；每次返回都检查是否保持暂停以及是否发生时间补算。
3. 验证通知实际显示与声音，包含拒绝授权后的继续使用。
4. 验证两张便签、失焦输入、窗口恢复、选区转换和多屏；用可控时钟验证跨日与重启。
5. 归档每项通过/未通过/受限的证据，完成发布包截图和资源采样。

### P2：完成日常体验的小增强

优先考虑待办删除撤销、便签新建位置错开、明确的 Dock 开关、数据备份入口。先测量长期数据量与写入成本；当前原子 JSON 可以继续支撑 Demo，是否迁移 SQLite 应依据长时数据和性能结果决定。

## 后续能力的可行性

| 后续能力 | 可行性与建议 |
| --- | --- |
| 用户主动选图与本地 OCR | 可行。Apple Vision 支持设备内文本识别。先做“用户选图 → 本地 OCR → 关联某一天或某轮专注”，保留图片来源与识别结果，便于用户核对 |
| 图片与记录辅助总结 | 从现有稳定 ID 和结构化统计继续扩展是可行的。建议先让用户确认图片和可发送的内容，再组合当日统计生成摘要；区分事实、图片依据与模型推断。模型、费用和图片处理范围需另行确定 |
| 桌宠 | 原生 2D 动画技术可行，主要投入在素材、动作、交互与耗电控制。建议先接入待机、专注、休息、完成提醒等状态，桌宠只观察现有计时状态，不承担计时和数据保存 |
| 云同步与账号 | 可做，但新增冲突合并、认证、服务运行与隐私处理，明显扩大范围。适合在本地数据与迁移机制稳定之后单独规划 |

后续优先推荐“主动选图与图片辅助总结”：它更直接对应需求书中的回顾目标。桌宠可在核心版稳定后作为独立的体验增强。

## 技术依据

- [Apple：系统睡眠事件](https://developer.apple.com/documentation/appkit/nsworkspace/willsleepnotification)：系统睡眠与屏幕睡眠、用户会话切换是不同事件，不能互相代替验收。
- [Apple：用户会话退出事件](https://developer.apple.com/documentation/appkit/nsworkspace/sessiondidresignactivenotification)：公开语义是用户会话切换，不应直接作为所有锁屏情况的证明。
- [Apple：通知授权](https://developer.apple.com/documentation/usernotifications/asking-permission-to-use-notifications)：授权与各项通知设置需查询，实际显示与声音需另行观察。
- [Apple：跨应用窗口行为](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallapplications)：适用于浮动窗口与跨应用空间，仍带有系统适用条件；不代表所有全屏窗口上的无条件可见。
- 当前 macOS SDK：`Carbon.framework/Frameworks/HIToolbox.framework/Headers/CarbonEvents.h` 中 `HotKeyOptions` 与 `RegisterEventHotKey` 的注释，说明非独占及独占注册的行为。
- [Apple Vision：图像文本识别](https://developer.apple.com/documentation/vision/recognizing-text-in-images)：设备内 OCR 可作为后续主动选图流程的基础。
- [Apple SpriteKit](https://developer.apple.com/documentation/spritekit)：macOS 原生 2D 内容与动画能力，可支撑后续桌宠实现。
