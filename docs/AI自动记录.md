# AI 自动记录

本功能在开发分支实现，尚未发布。目的是让用户只需开始计时、正常做事，就能留下可回忆的活动记录；不要求每轮填目标、写总结或确认 AI。

## 开启与使用

1. 在“设置 → AI 助手”配置已有服务商和文字模型。
2. 在“AI 自动记录”卡中选择 Chrome 浏览材料、本轮便签与完成待办、App 时长辅助信息，开启总开关。设置中直接说明选中材料会保存到本机，并发送给当前配置的服务商。
3. 使用 Chrome 材料时，主动点击“允许读取 Chrome”。系统自动化授权与专注守护共用底层权限，但记录开关独立；不需要屏幕录制。
4. 直接开始专注。约两分钟且有足够材料后自动识别主题；到点或提前结束后先休息，AI 在后台整理。投入少于一分钟时保留本机记录，不自动总结。
5. 进展卡的“补一句”可快速追加文字，自动归入该轮；详情可修改主题、展开原始活动或删除材料。今日页将明确关联到同一主题的轮次合并展示，仍可逐轮打开。

总开关默认关闭。关闭后停止新增采集与主题识别，保留已有本机资料；已发出的请求无法撤回。旧的“每轮专注后整理成果”与定时日报仍有各自的开关。AI 自动记录已包含本轮结束总结，无需重复开启旧选项；两个都开启也不会重复自动整理同一轮。

没有 Key 时可以先保存本机活动，后续新材料可触发识别；没有为结束轮次补跑历史的后台扫描，需要时可手动总结。

## 采集范围

| 来源 | 保存内容 | 边界 |
| --- | --- | --- |
| Chrome 普通前台页面 | 清理后的标题、网站、专注中的时间分段、采样停留秒数 | 每约 5 秒读取，只有相邻两次同一前台标签与标题均一致时才累计，并裁切到计时引擎确认的专注区间；切换边界、首尾几秒可能漏记，不能当作精确阅读时长 |
| 便签 | 本轮新写入或修改的行，最长 1200 字的变更片段 | 不把旧便签全文或旧首行送入记录；同一连续采集段合并打字过程，暂停 / 重新授权后另留分段。删除文字后原片段不再继续作为当前变更 |
| 待办 | 专注运行中勾选完成的文字与时间 | 暂停、休息中的操作不归入本轮；仍保留原待办功能 |
| App 辅助信息 | 已有前台 App 名称与秒数 | 需同时开启原 App 明细记录；单有 App 名称不能判断具体任务 |

仅在专注运行且未锁屏时采集。暂停、休息、睡眠和退出时中止采样，恢复时不补记空档。跨日记录按已确认的专注日期切分。

不读取无痕标签、内部页、`file:` 页面、网页正文、PDF 页码、编辑器内容、浏览历史、键盘输入或剪贴板；不自动截图。Chrome 临时读取到的 URL 仅在内存用于提取网站，路径、查询参数、窗口 / 标签标识不进入持久化资料。标题里直接出现的 HTTP(S) 网址也会清理为网站。标题和用户文字自身仍可能包含私人信息，应通过来源开关自行选择。

守护截图继续按原来的逐轮授权使用，不变成活动记录或成果附件；AI 自动记录不关闭网页。

## AI 行为

流程为：本机采集与合并 → 带材料 ID 的主题请求 → 保存初步主题 → 结束时整理活动 → 今日按主题展示。

- 第一次主题识别需至少 120 秒实际专注，且累计至少 45 秒的有效页面材料或已有便签 / 完成待办。少于 15 秒的单段页面不进入 AI 上下文，避免短暂切换主导命名。
- 进行中最多 4 次识别；后续判断须有新材料，且距离上次已累计至少 5 分钟专注。计时增长本身不算新材料，同一批失败输入不反复请求。结束时如有新材料且尚未尝试，可再识别一次。
- 仅接受置信度至少 0.75 且引用真实本轮材料 ID 的主题。虚构材料、越界置信度、未知主题关联或截断响应均拒绝保存。信息不足时允许空主题，继续显示“正在记录”。
- 手动目标保留原来的计划含义；AI 主题单独保存。手动修改的记录名称优先，当前轮次不再被 AI 覆盖。未来轮次可以在新证据支持时参考用户纠正的名称，不训练模型，也不把旧轮成果当作新轮证据。
- 同主题关联由 AI 返回已有主题 ID，并校验其确实在提供的候选中；无法确认时独立成组。不会只因连续使用同一个 App 就合并。
- 结束且投入至少 60 秒后自动尝试一次回顾，失败不循环重试，不补扫过去轮次。没有 AI 结果时原始活动、计时与待办仍保留。
- 页面标题只支持“浏览 / 查阅相关材料”，便签变更只支持“写下 / 修改相关文字”。提示词要求不从停留时间推断读完、掌握、测试通过或任务完成，没有依据时成果为空。

主题请求只使用文字。最终回顾继续复用现有多服务商客户端；用户主动附上的图片仍遵守原回顾规则。最繁忙的一轮最多 5 次主题请求与 1 次自动回顾；定时日报、主动重试与守护判断另计。

每轮详情展示原始活动，主题有经过校验的依据 ID；当前提供轮次级依据查看，尚未实现每一条总结逐项跳转材料。AI 内容仍可能理解错误。

## 修改、删除与兼容

- 删除活动会同时删除该轮同一来源的分段，在该轮持久化排除该材料，并清除依赖的轮次与当日日报总结。不会删除原便签、待办或浏览器标签。
- 请求使用配置与资料变更标记隔离。用户改名、删除或更换来源 / 服务商后，之前返回的主题或总结不会重新覆盖当前记录。
- 资料格式由 v3 升级为 v4。读取旧资料先在 `Backups/schema-v3` 等目录保留原始 JSON 与引用附件；旧开关默认不变，自动记录默认关闭。备份、资料合并包含活动记录，冲突时沿用拒绝覆盖规则。
- 没有修改版本号或发布标签；旧版应用不支持 v4，回退前需要恢复兼容备份。

- UI、真实 Chrome 自动化权限 / 页面切换与真实服务商调用是独立验收项目，不能由模拟接口通过代替。本轮未重新进行此前暂停的实机界面自动化，没有使用个人待办、便签或浏览标签做测试。
