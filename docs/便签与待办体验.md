# 便签与待办体验

## 顶部入口

顺序为 **专注 / 待办 / 今日 / 便签 / 设置**。待办从专注页下方移至独立页面，切换页面从顶部开始；玻璃选中层保留连续滑动，标签文字独立于玻璃层。玻璃开关、浅色 / 深色和系统辅助功能继续生效。

## 一日清单

- 回车或点加号添加今天的待办；文字支持双击或右键修改。
- 勾选框有按下反馈和描画勾号，完成后保留原位置、划线、显示完成时间；进度环同步更新，出现短暂的完成提示。
- 当前清单全部完成时出现“完成”印章；新增任务或撤回完成后恢复普通进度。反馈来自真实完成数量，不生成虚构积分。
- 支持设备在完成时提供轻触感反馈，不额外播放音效或弹出阻断窗口。“减少动态效果”关闭移动、缩放与描画动画，仍保留文字和勾选状态。
- 再点一次勾选可撤回。待办仍只属于创建当天，不自动结转；过去日期在“今日”里查看。
- 沿用现有记录：专注分段内完成的待办可进入该轮进展；暂停或休息中完成的待办不会被归入上一轮。清单交互本身不调用 AI。

## 便签与历史

便签页默认显示今天创建或从历史继续使用的便签。顶部“历史便签”显示旧便签数量，进入后按归档日期由近到远分组。

| 操作 | 结果 |
| --- | --- |
| 点击正文 | 打开对应便签原窗口 |
| 历史 → 继续使用 | 复制文字与窗口尺寸到今天，分配新 ID、重置窗口位置，打开今日副本 |
| 同一天再次继续同一原稿 | 打开已有的今日副本，不覆盖已经补写的内容 |
| 下一天继续 | 创建下一天自己的副本 |
| 删除 | 确认单张便签后删除，并关闭对应浮动窗口；其他原稿和副本独立保留 |
| 回到今天 / 重新进入便签页 | 显示今天的便签，从列表顶部开始 |
| 便签快捷键 | 打开今天最近使用的便签，今天没有时新建 |

继续使用前会保存仍打开的原稿编辑；原稿的文字、创建日期和 ID 保留。已有浮动便签不会因为归档而自动关闭。删除不是收起，确认后不能从应用内撤销；收起窗口仍可从对应日期重新打开。

### 数据兼容

`StickyNote.localDay` 保存新便签创建时的本地日期，`continuedFromNoteID` 记录副本来源。两者为可选字段，保持 v2 数据可读；老便签缺少日期字段时使用创建时间。打开、收起和编辑改变 `updatedAt`，不会改变便签所属日期。非今日记录均可从历史找到，包括系统时钟或时区调整产生的其他日期。

显示层通过 `NoteLibrary` 获取日期分组；操作由 `AppState` 写入原有资料库，`NoteWindows` 负责打开和关闭对应窗口。删除数据后才关闭窗口，关闭回调与延迟保存会忽略已不存在的 ID，防止重新写回已删除的便签。

### 人工验收

请使用独立验证资料，避免拿重要便签测试删除。

1. 连续切换五个顶部入口，检查文字清晰、点击范围与玻璃选中层滑动；切换前先滚动，返回后应从顶部开始。
2. 在待办页用中文输入并回车添加两项，双击修改，完成其中一项：勾号、划线、完成时间与进度一致。
3. 完成所有项看到印章；再次勾选撤回，印章消失且完成数减少。切换页面、重启后状态仍保留。
4. 新建今天的便签并收起，默认列表可找到；历史列表按日期分组，今天的便签不会重复出现。
5. 对历史便签点“继续使用”，在今日副本补写内容。再次继续同一原稿应打开该副本，原稿和补写均保留。
6. 删除一张已打开的测试便签，窗口应关闭；其他便签和副本保留，重启后删除项不会重新出现。取消删除应不改变资料。
7. 跨午夜保持应用运行，前一天便签进入历史；分别检查浅色、深色、玻璃开关与系统“减少动态效果”。

原生自动化此前反复出现 ScreenCaptureKit 错误，按用户要求停止重复实机尝试；上述真实点击、删除窗口、玻璃动画与触感仍待人工验收。
